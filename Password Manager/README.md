# Secure Password Manager

A comprehensive, secure password manager built with Python featuring encryption, GUI, and cloud sync capabilities.

## Features

- 🔐 **AES-256 Encryption** - Military-grade encryption for your passwords
- 🖥️ **Modern GUI** - Clean, intuitive interface built with tkinter
- ☁️ **Cloud Sync** - Optional Google Drive synchronization
- 🎯 **Password Generator** - Create strong, random passwords
- 📊 **Strength Analysis** - Assess password strength
- 🔍 **Search & Filter** - Quickly find your passwords
- 🏷️ **Categories** - Organize passwords by type
- ⏰ **Auto-lock** - Automatic session locking for security
- 💾 **Backups** - Local and cloud backup options
