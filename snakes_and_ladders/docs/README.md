# Snakes and Ladders 🐍🪜

A comprehensive, multi-feature implementation of the classic Snakes and Ladders board game in Python.

## Features

### 🎮 Gameplay
- Multiple players (2-4)
- Configurable board sizes
- Multiple difficulty levels
- Special positions with effects
- Double dice roll bonuses
- Turn history and statistics

### 🎨 Interfaces
- **Console UI**: Full-featured terminal interface
- **Graphical UI**: Pygame-based visual interface
- Animations and sound effects
- Multiple color themes

### 💾 Save System
- Save/load game state
- Multiple save slots
- Automatic save management

### 🧪 Testing
- Comprehensive unit tests
- Player movement tests
- Board logic tests
